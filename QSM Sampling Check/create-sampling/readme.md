# 🧪 Create Sampling Details

## 1. วัตถุประสงค์ของหน้า Create Sampling

หน้า **Create Sampling** ใช้สำหรับสร้างข้อมูล Sampling และ QR Code สำหรับการเก็บตัวอย่างผลิตภัณฑ์นม ถือเป็นขั้นตอนแรกของกระบวนการทำงานในส่วน Production

ผู้ใช้งานสามารถสร้าง Sampling เพื่อบันทึกข้อมูลตามช่วงเวลาการผลิตของแต่ละกะ โดยระบบกำหนดข้อมูลที่ต้องกรอกทั้งหมด 9 รายการ ดังนี้

---

## 2. รายละเอียดข้อมูลที่ใช้สร้าง Sampling

| ลำดับ | Field         | รายละเอียด                                         |
| ----: | ------------- | -------------------------------------------------- |
|     1 | `FillingDate` | วันที่ผลิตสินค้า                                   |
|     2 | `ExpiredDate` | วันหมดอายุของสินค้า                                |
|     3 | `Product`     | ชื่อผลิตภัณฑ์ที่ผลิต โดยเลือกจากรายการที่ระบบกำหนด |
|     4 | `Products`    | ชื่อผลิตภัณฑ์เพิ่มเติม กรณีเลือก `Other`           |
|     5 | `Flavour`     | รสชาติหรือกลิ่นของผลิตภัณฑ์                        |
|     6 | `Department`  | แผนกที่ทำการสร้าง Sampling                         |
|     7 | `Machine`     | เครื่องจักรที่ใช้ในการผลิต                         |
|     8 | `Size`        | ขนาดของผลิตภัณฑ์                                   |
|     9 | `SamplingID`  | รหัสประจำ Sampling ที่ระบบสร้างขึ้นโดยอัตโนมัติ    |

---

## 3. รายละเอียดแต่ละ Field

### 3.1 `FillingDate`

วันที่ผลิตผลิตภัณฑ์

---

### 3.2 `ExpiredDate`

วันหมดอายุของผลิตภัณฑ์

---

### 3.3 `Product`

ชื่อผลิตภัณฑ์ที่ผลิต โดยระบบจะแสดงรายการให้เลือก ดังนี้

```text
D-Malt
D-Whitemalt
UHT-Mik
Other
```

---

### 3.4 `Products`

ช่องสำหรับระบุชื่อผลิตภัณฑ์เพิ่มเติมที่ไม่มีอยู่ในรายการ `Product`

ช่องนี้จะแสดงเฉพาะเมื่อผู้ใช้งานเลือก:

```text
Product = Other
```

---

### 3.5 `Flavour`

รายละเอียดรสชาติหรือกลิ่นของผลิตภัณฑ์ที่ผลิต

---

### 3.6 `Department`

ชื่อแผนกที่ทำการสร้าง Sampling โดยผู้ใช้งานเลือกข้อมูลผ่าน Dropdown

---

### 3.7 `Machine`

เครื่องจักรที่ใช้ในการผลิต โดยผู้ใช้งานเลือกข้อมูลผ่าน Dropdown

รายการเครื่องจักรจะเชื่อมโยงจาก Data Provider:

```text
Query Get All Machine
```

---

### 3.8 `Size`

ขนาดของผลิตภัณฑ์ โดยข้อมูลจะเชื่อมโยงกับฐานข้อมูลของเครื่องจักร และแสดงผลผ่าน Dropdown ตามเครื่องจักรที่เลือก

---

### 3.9 `SamplingID`

รหัสประจำ Sampling ซึ่งระบบจะสร้างขึ้นโดยอัตโนมัติ เพื่อนำไปใช้สร้าง QR Code สำหรับระบุข้อมูล Sampling

รูปแบบรหัสมีโครงสร้างดังนี้:

```text
ชื่อระบบ-วันที่ผลิต-รหัสแผนกและเครื่องจักร-ลำดับประจำวัน
```

ตัวอย่าง:

```text
QSM-07012026-06014-01
```

### ส่วนประกอบของ SamplingID

| ส่วนประกอบ | ความหมาย                        |
| ---------- | ------------------------------- |
| `QSM`      | ชื่อระบบ                        |
| `07012026` | วันที่ผลิต                      |
| `06014`    | รหัสแผนกและเครื่องจักร          |
| `01`       | ลำดับการสร้าง Sampling ประจำวัน |

---

## 4. 🔢 หลักการกำหนดลำดับ Sampling

ระบบจะกำหนดลำดับ Sampling โดยอัตโนมัติ ตามหลักการดังนี้:

* การสร้าง Sampling ครั้งแรกของวัน จะเริ่มต้นที่ลำดับ `01`
* หากสร้าง Sampling เพิ่มภายในวันเดียวกัน ระบบจะเพิ่มลำดับเป็น `02`, `03`, `04` ตามลำดับ
* เมื่อเปลี่ยนเป็นวันใหม่ ระบบจะรีเซ็ตลำดับกลับมาเริ่มต้นที่ `01`
* ระบบจะนำรหัสแผนก รหัสเครื่องจักร และวันที่ผลิตมาใช้ประกอบการสร้าง SamplingID
* SamplingID ที่สร้างขึ้นจะถูกนำไปใช้สำหรับสร้าง QR Code และเชื่อมโยงข้อมูลในขั้นตอนถัดไป

---

## 5. 🔄 ลำดับการทำงานของหน้า Create Sampling

1. ผู้ใช้งานกรอกวันที่ผลิตและวันหมดอายุ
2. เลือกผลิตภัณฑ์จากรายการที่กำหนด
3. กรอกชื่อผลิตภัณฑ์เพิ่มเติม หากเลือก `Other`
4. ระบุรสชาติหรือกลิ่นของผลิตภัณฑ์
5. เลือกแผนกและเครื่องจักร
6. เลือกขนาดผลิตภัณฑ์
7. ระบบสร้าง `SamplingID` อัตโนมัติ
8. ระบบสร้าง QR Code สำหรับ Sampling
9. บันทึกข้อมูลลงในระบบ
10. นำ Sampling ไปใช้ในขั้นตอน Record Data ต่อไป
