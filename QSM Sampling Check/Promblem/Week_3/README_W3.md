## 🛠️ งานที่ดำเนินการ

- ออกแบบโปรแกรมสำหรับส่งและรับข้อมูลให้แผนก QA
- ออกแบบ Query และโครงสร้างฐานข้อมูล
- เพิ่มหน้าสำหรับบันทึกข้อมูลการส่งตัวอย่าง

## ⚠️ ปัญหาที่พบ

1. ข้อมูลบางส่วนที่ต้องใช้รับข้อมูลจากผู้ส่งยังไม่ครบถ้วน
2. พบปัญหาในการเชื่อมโยงข้อมูลระหว่าง Sampling และ Product ขณะกรอกข้อมูล
3. การตรวจสอบข้อมูลในแต่ละกะทำได้ไม่สะดวก

## ✅ วิธีการแก้ไข

- ปรับโครงสร้างฐานข้อมูลให้รองรับข้อมูลตามการทำงานจริง
- สอบถามพนักงานที่เกี่ยวข้องเพื่อเก็บข้อมูลที่จำเป็นและลดความซับซ้อนของระบบ
- เพิ่ม Option สำหรับเลือกกะ เพื่อดูข้อมูลกะปัจจุบันหรือข้อมูลย้อนหลัง

## 🎯 ผลลัพธ์

> ✅ ระบบรองรับการบันทึกข้อมูลการส่งตัวอย่างได้ชัดเจนขึ้น และสามารถเลือกกะเพื่อตรวจสอบข้อมูลย้อนหลังได้
