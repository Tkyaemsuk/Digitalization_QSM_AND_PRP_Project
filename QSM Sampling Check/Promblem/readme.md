## 🔍 รายละเอียดปัญหาและวิธีการแก้ไข

### 🟦 สัปดาห์ที่ 1 — MSWS / เริ่มต้นใช้งาน Budibase

#### 🛠️ งานที่ดำเนินการ

- ฝึกใช้งานโปรแกรม Budibase
- ทดลองสร้างระบบ Login และกำหนดสิทธิ์การเข้าใช้งาน
- ทดลอง Scan ข้อมูลจาก QR Code
- ใช้ CheckBox และ Option สำหรับเลือกข้อมูล
- ทดลอง Query เพื่อดึง `ProductID`
- ทดลองส่ง Parameters และเชื่อมโยงหน้าเพจภายในแอปพลิเคชัน
- สร้างหน้า Report โดยใช้ Query และ Conditions

#### ⚠️ ปัญหาที่พบ

1. เมื่อ Scan QR Code แล้วสามารถดึงข้อมูลได้ไม่ครบถ้วน
2. เกิดข้อผิดพลาดจากการเรียงลำดับขั้นตอนการดำเนินการในแอปพลิเคชัน

#### ✅ วิธีการแก้ไข

- พูดคุยและปรับความเข้าใจเกี่ยวกับลำดับการเริ่มต้นสร้างแอปพลิเคชัน
- ตรวจสอบขั้นตอนการทำงานเพื่อค้นหาจุดที่ทำให้ข้อมูลสูญหายหรือถูกส่งต่อไม่ครบ
- ทดลองใช้งานหลายรูปแบบ เพื่อเปรียบเทียบผลลัพธ์และหาวิธีที่ถูกต้อง

#### 🎯 ผลลัพธ์

> ✅ สามารถเข้าใจพื้นฐานการสร้างแอปพลิเคชันบน Budibase รวมถึงการทำงานของ Login, การกำหนดสิทธิ์, การ Scan QR Code, การ Query และการเชื่อมโยงหน้า Report ได้ดีขึ้น

---

### 🟨 สัปดาห์ที่ 2 — QSM / ศึกษากระบวนการทำงานและออกแบบฐานข้อมูล

#### 🛠️ งานที่ดำเนินการ

- ลงพื้นที่จริงเพื่อศึกษาขั้นตอนการทำงาน
- เรียงลำดับความสัมพันธ์ของข้อมูลและกระบวนการทำงาน
- ออกแบบหน้าตาแอปพลิเคชัน
- ออกแบบฐานข้อมูลสำหรับบันทึกข้อมูล
- สอบถามข้อมูลจากพนักงานในแต่ละจุดปฏิบัติงาน

#### ⚠️ ปัญหาที่พบ

1. เกิดความสับสนระหว่างการพูดคุยเกี่ยวกับลำดับขั้นตอนการทำงาน
2. ฐานข้อมูลมีความซับซ้อน ทำให้การบันทึกข้อมูลทำได้ยาก
3. ข้อมูลบางส่วนจากผู้ส่งยังไม่ครบถ้วนหรือยังไม่ทราบรายละเอียดที่จำเป็น

#### ✅ วิธีการแก้ไข

- สอบถามพนักงานในแต่ละฝ่ายเพื่อทำความเข้าใจกระบวนการทำงานจริง
- ปรับโครงสร้างฐานข้อมูลให้สอดคล้องกับขั้นตอนและความต้องการของผู้ใช้งาน
- ตรวจสอบข้อมูลที่ได้รับและระบุข้อมูลที่ยังขาด เพื่อขอรายละเอียดเพิ่มเติมจากผู้เกี่ยวข้อง

#### 🎯 ผลลัพธ์

> ✅ ได้โครงสร้างกระบวนการทำงานและแนวทางการออกแบบฐานข้อมูลที่สอดคล้องกับการทำงานจริงมากขึ้น

---

### 🟩 สัปดาห์ที่ 3 — QSM / ระบบรับ–ส่งข้อมูลและบันทึกตัวอย่าง

#### 🛠️ งานที่ดำเนินการ

- ออกแบบโปรแกรมสำหรับส่งและรับข้อมูลให้แผนก QA
- ออกแบบ Query และโครงสร้างฐานข้อมูล
- เพิ่มหน้าสำหรับบันทึกข้อมูลการส่งตัวอย่าง

#### ⚠️ ปัญหาที่พบ

1. ข้อมูลบางส่วนที่ต้องใช้รับข้อมูลจากผู้ส่งยังไม่ครบถ้วน
2. พบปัญหาในการเชื่อมโยงข้อมูลระหว่าง Sampling และ Product ขณะกรอกข้อมูล
3. การตรวจสอบข้อมูลในแต่ละกะทำได้ไม่สะดวก

#### ✅ วิธีการแก้ไข

- ปรับโครงสร้างฐานข้อมูลให้รองรับข้อมูลตามการทำงานจริง
- สอบถามพนักงานที่เกี่ยวข้องเพื่อเก็บข้อมูลที่จำเป็นและลดความซับซ้อนของระบบ
- เพิ่ม Option สำหรับเลือกกะ ทำให้สามารถตรวจสอบข้อมูลของกะปัจจุบันหรือดูข้อมูลย้อนหลังได้

#### 🎯 ผลลัพธ์

> ✅ ระบบรองรับการบันทึกข้อมูลการส่งตัวอย่างได้ชัดเจนขึ้น และสามารถเลือกกะเพื่อค้นหาหรือตรวจสอบข้อมูลย้อนหลังได้

---

### 🟪 สัปดาห์ที่ 4 — QSM / ออกแบบระบบรับ–ส่งตัวอย่างนม

#### 🛠️ งานที่ดำเนินการ

- ออกแบบหน้าโปรแกรมสำหรับรับ–ส่งตัวอย่างนม
- ลงพื้นที่ศึกษาและตรวจสอบขั้นตอนการทำงานของแผนก
- ออกแบบฐานข้อมูลให้สอดคล้องกับกระบวนการทำงาน

#### ⚠️ ปัญหาที่พบ

เกิดความสับสนระหว่างการพูดคุยและเรียงลำดับขั้นตอนการทำงานของแต่ละฝ่าย ทำให้การออกแบบระบบในช่วงแรกยังไม่ตรงกับกระบวนการจริง

#### ✅ วิธีการแก้ไข

- สอบถามพนักงานของแต่ละฝ่ายโดยตรง
- เปรียบเทียบข้อมูลจากการสัมภาษณ์กับขั้นตอนการทำงานจริงในพื้นที่
- ปรับแนวทางการออกแบบระบบและฐานข้อมูลให้ตรงกับลำดับงานที่ตรวจสอบแล้ว

#### 🎯 ผลลัพธ์

> ✅ เข้าใจกระบวนการรับ–ส่งตัวอย่างนมมากขึ้น และสามารถนำข้อมูลจากหน้างานมาใช้ปรับปรุง Design Database ได้เหมาะสมยิ่งขึ้น

---

### 🟧 สัปดาห์ที่ 5 — MSWS / จัดทำ Product Report

#### 🛠️ งานที่ดำเนินการ

- จัดทำ Report จากข้อมูล Product Report
- ออกแบบเมนูสำหรับเชื่อมโยงไปยังเอกสาร
- พัฒนา Report สำหรับดึงข้อมูลมาแสดงผล

#### ⚠️ ปัญหาที่พบ

1. ฐานข้อมูลมีความซับซ้อน จึงไม่สามารถระบุวิธีดึงข้อมูลมาแสดงใน Report ได้ทันที
2. ไม่พบรหัสพนักงานในระบบ ทำให้ไม่สามารถเชื่อมโยงข้อมูลพนักงานได้

#### ✅ วิธีการแก้ไข

- วิเคราะห์โครงสร้างฐานข้อมูลตั้งแต่ต้น
- ตรวจสอบความสัมพันธ์ของตารางและข้อมูลที่เกี่ยวข้อง ก่อนนำมาเขียน Query
- แจ้งหัวหน้างานเกี่ยวกับปัญหารหัสพนักงาน เพื่อขอข้อมูลหรือแนวทางดำเนินการต่อ

#### 🎯 ผลลัพธ์

> ✅ ได้แนวทางในการวิเคราะห์ฐานข้อมูลและเตรียม Query สำหรับ Report อย่างเป็นระบบมากขึ้น รวมถึงทราบข้อมูลที่ต้องประสานงานเพิ่มเติมกับผู้ดูแลระบบ

---

### 🟥 สัปดาห์ที่ 6 — MSWS / ปรับปรุงหน้า Report และข้อมูลพนักงาน

#### 🛠️ งานที่ดำเนินการ

- ตกแต่งและเพิ่มลูกเล่นให้หน้า Report ของแอปพลิเคชัน
- เพิ่มวันที่เริ่มใช้งานและรหัสเอกสารบริเวณด้านล่างของทุกหน้า
- ดึงชื่อพนักงานมาแสดงโดยอ้างอิงจากรหัสพนักงาน

#### ⚠️ ปัญหาที่พบ

ฐานข้อมูลยังไม่มีข้อมูลรหัสพนักงานที่อัปเดต จึงไม่สามารถค้นหาและแสดงชื่อพนักงานที่ตรงกับรหัสได้

#### ✅ วิธีการแก้ไข

- ติดต่อฝ่ายทรัพยากรบุคคล (HR)
- ขอข้อมูลพนักงานเพิ่มเติมและข้อมูลรหัสพนักงานฉบับปัจจุบัน
- เตรียมนำข้อมูลที่ได้รับไปปรับปรุงการเชื่อมโยงระหว่างรหัสพนักงานกับชื่อพนักงานใน Report

#### 🎯 ผลลัพธ์

> ✅ สามารถระบุสาเหตุของปัญหาได้ชัดเจนว่าเกิดจากข้อมูลต้นทางยังไม่อัปเดต และมีแนวทางประสานงานกับ HR เพื่อแก้ไขข้อมูลให้ถูกต้อง

---

## 🧩 สรุปแนวทางการแก้ไขที่ใช้ร่วมกัน

จากปัญหาทั้งหมด สามารถสรุปแนวทางการทำงานที่ใช้ในการแก้ไขปัญหาได้ดังนี้

1. 🔎 **ศึกษากระบวนการทำงานจริง** โดยลงพื้นที่และสังเกตขั้นตอนการทำงานของแต่ละฝ่าย
2. 💬 **สอบถามผู้ปฏิบัติงานโดยตรง** เพื่อให้ได้ข้อมูลที่ถูกต้องและลดความคลาดเคลื่อนในการตีความ
3. 🗄️ **วิเคราะห์โครงสร้างและความสัมพันธ์ของฐานข้อมูล** ก่อนออกแบบ Query หรือสร้าง Report
4. 🔧 **ปรับโครงสร้างฐานข้อมูลและลำดับการทำงาน** ให้สอดคล้องกับความต้องการของผู้ใช้งาน
5. 🧪 **ทดลองใช้งานและตรวจสอบผลลัพธ์** เพื่อค้นหาข้อผิดพลาดจากการส่งข้อมูล การ Scan หรือการเชื่อมโยงหน้าเพจ
6. 🤝 **ประสานงานกับหน่วยงานที่เกี่ยวข้อง** เช่น หัวหน้างานและฝ่าย HR เมื่อข้อมูลต้นทางไม่ครบถ้วนหรือจำเป็นต้องอัปเดต
