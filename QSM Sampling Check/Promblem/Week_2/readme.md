## 🛠️ งานที่ดำเนินการ

- ลงพื้นที่จริงเพื่อศึกษาขั้นตอนการทำงาน
- เรียงลำดับความสัมพันธ์ของข้อมูลและกระบวนการทำงาน
- ออกแบบหน้าตาแอปพลิเคชัน
- ออกแบบฐานข้อมูลสำหรับบันทึกข้อมูล
- สอบถามข้อมูลจากพนักงานในแต่ละจุดปฏิบัติงาน

## ⚠️ ปัญหาที่พบ

1. เกิดความสับสนระหว่างการพูดคุยเกี่ยวกับลำดับขั้นตอนการทำงาน
2. ฐานข้อมูลมีความซับซ้อน ทำให้การบันทึกข้อมูลทำได้ยาก
3. ข้อมูลบางส่วนจากผู้ส่งยังไม่ครบถ้วนหรือยังไม่ทราบรายละเอียดที่จำเป็น

## ✅ วิธีการแก้ไข

- สอบถามพนักงานในแต่ละฝ่ายเพื่อทำความเข้าใจกระบวนการทำงานจริง
- ปรับโครงสร้างฐานข้อมูลให้สอดคล้องกับขั้นตอนและความต้องการของผู้ใช้งาน
- ตรวจสอบข้อมูลที่ได้รับและระบุข้อมูลที่ยังขาด เพื่อขอรายละเอียดเพิ่มเติมจากผู้เกี่ยวข้อง

## 🎯 ผลลัพธ์

> ✅ ได้โครงสร้างกระบวนการทำงานและแนวทางการออกแบบฐานข้อมูลที่สอดคล้องกับการทำงานจริงมากขึ้น
