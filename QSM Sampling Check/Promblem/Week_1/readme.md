![Project](https://img.shields.io/badge/Project-MSWS-0F766E?style=for-the-badge)

## 🛠️ งานที่ดำเนินการ

- ฝึกใช้งานโปรแกรม Budibase
- ทดลองสร้างระบบ Login และกำหนดสิทธิ์การเข้าใช้งาน
- ทดลอง Scan ข้อมูลจาก QR Code
- ใช้ CheckBox และ Option สำหรับเลือกข้อมูล
- ทดลอง Query เพื่อดึง `ProductID`
- ทดลองส่ง Parameters และเชื่อมโยงหน้าเพจภายในแอปพลิเคชัน
- สร้างหน้า Report โดยใช้ Query และ Conditions

## ⚠️ ปัญหาที่พบ

1. เมื่อ Scan QR Code แล้วสามารถดึงข้อมูลได้ไม่ครบถ้วน
2. เกิดข้อผิดพลาดจากการเรียงลำดับขั้นตอนการดำเนินการในแอปพลิเคชัน

## ✅ วิธีการแก้ไข

- พูดคุยและปรับความเข้าใจเกี่ยวกับลำดับการเริ่มต้นสร้างแอปพลิเคชัน
- ตรวจสอบขั้นตอนการทำงานเพื่อค้นหาจุดที่ทำให้ข้อมูลสูญหายหรือถูกส่งต่อไม่ครบ
- ทดลองใช้งานหลายรูปแบบ เพื่อเปรียบเทียบผลลัพธ์และหาวิธีที่ถูกต้อง

## 🎯 ผลลัพธ์

> ✅ เข้าใจพื้นฐานการสร้างแอปพลิเคชันบน Budibase รวมถึง Login, การกำหนดสิทธิ์, การ Scan QR Code, การ Query และการเชื่อมโยงหน้า Report ได้ดีขึ้น
