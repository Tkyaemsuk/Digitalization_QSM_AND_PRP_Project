# 📝 Record Data Details

## 1. การเข้าสู่หน้า Record Data

เมื่อผู้ใช้งานกดปุ่ม **Record Data** ระบบจะเปิดหน้า URL พร้อมส่งค่า `SamplingID` ผ่าน URL Parameter

ตัวอย่าง:

```text
/record-data/QSM-07012026-06014-01
```

เมื่อเข้าสู่หน้า Record Data ระบบจะดำเนินการดังนี้:

1. Data Provider รับค่า `SamplingID` จาก URL
2. ตรวจสอบว่ามี `SamplingID` ดังกล่าวอยู่ในระบบหรือไม่
3. หากพบข้อมูล ระบบจะแสดงรายละเอียด Sampling
4. ผู้ใช้งานสามารถบันทึกข้อมูลตัวอย่างนมตามอุณหภูมิที่กำหนด

ระบบจะแบ่งการบันทึกข้อมูลออกเป็น 2 อุณหภูมิ โดยเริ่มจาก:

1. อุณหภูมิ 30°C
2. อุณหภูมิ 55°C

---

## 2. 🧪 Record Data: อุณหภูมิ 30°C

```text
SamplingID: QSM-07012026-06014-01
Temperature: 30°C
```

|        No. | Code / Time         | Status             | Amount | Action |
| ---------: | ------------------- | ------------------ | -----: | ------ |
| ลำดับกล่อง | เวลาที่เก็บตัวอย่าง | Start / Stop / Hr. |  จำนวน | Save   |

### รายละเอียดข้อมูล

* **No.** — ลำดับของกล่องนม
* **Code / Time** — รหัสหรือเวลาที่เก็บตัวอย่าง
* **Status** — สถานะของการเก็บตัวอย่าง ได้แก่ `Start`, `Stop` และ `Hr.`
* **Amount** — จำนวนตัวอย่างหรือจำนวนกล่องนม
* **Save** — ปุ่มสำหรับบันทึกข้อมูล

## 4. 🔢 การกำหนดลำดับกล่องนม

ระบบจะใช้ Query ตรวจสอบข้อมูลเดิมจาก `SamplingID` และอุณหภูมิที่เลือก เพื่อกำหนดลำดับกล่องนมโดยอัตโนมัติ

### หลักการทำงาน

* หาก SamplingID ยังไม่มีข้อมูล ระบบจะเริ่มลำดับที่ `1`
* หากมีข้อมูลเดิมอยู่แล้ว ระบบจะนับต่อจากลำดับล่าสุด
* ตัวอย่างเช่น หากมีข้อมูลล่าสุดเป็นกล่องที่ `10` ระบบจะกำหนดกล่องถัดไปเป็นลำดับที่ `11`
* เมื่อบันทึกข้อมูลกล่องที่ `11` สำเร็จ ระบบจะเปลี่ยนลำดับถัดไปเป็น `12` โดยอัตโนมัติ
* การนับลำดับของอุณหภูมิ 30°C และ 55°C จะดำเนินการแยกจากกัน

เมื่อผู้ใช้งานบันทึกข้อมูลครบถ้วนตามรอบการทำงานของตนเองแล้ว ให้กดปุ่ม **Send Sampling** เพื่อส่งข้อมูลเข้าสู่ขั้นตอนถัดไป

# 📤 Sending Sampling

## 5. การส่งข้อมูล Sampling

เมื่อผู้ใช้งานกดปุ่ม **Send Sampling** ระบบจะนำเข้าสู่หน้าตรวจสอบข้อมูลก่อนส่ง Sampling

หน้าดังกล่าวจะมีรูปแบบใกล้เคียงกับหน้า `/create-sampling` แต่จะมีข้อจำกัดดังนี้:

* ไม่สามารถแก้ไขข้อมูล Sampling ได้
* แสดงข้อมูล Sampling ที่บันทึกไว้ในระบบ
* แสดงรายงานข้อมูลตัวอย่างนมของแต่ละอุณหภูมิ
* แสดงจำนวนข้อมูลที่บันทึกไว้ในอุณหภูมิ 30°C และ 55°C

---

## 6. 👥 การบันทึกข้อมูลพนักงานแต่ละกะ

ในหน้าส่ง Sampling ระบบจะมีช่องสำหรับกรอกรหัสพนักงานที่เข้าปฏิบัติงานในแต่ละกะ โดยใช้ช่องข้อมูลดังนี้:

```text
Shift_1
Shift_2
Shift_3
Shift_4
```

ระบบจะเปิดใช้งานช่องกรอกข้อมูลตามลำดับทั้งหมด 4 รอบ

### ลำดับการทำงาน

1. ผู้ใช้งานกรอกรหัสพนักงานในช่อง `Shift_1`
2. เมื่อบันทึกข้อมูลแล้ว ระบบจะแสดงช่อง `Shift_2`
3. เมื่อกรอกข้อมูลใน `Shift_2` แล้ว ระบบจะแสดงช่อง `Shift_3`
4. เมื่อกรอกข้อมูลใน `Shift_3` แล้ว ระบบจะแสดงช่อง `Shift_4`
5. เมื่อกรอกข้อมูลครบทั้ง 4 รอบ ระบบจะถือว่าการบันทึกข้อมูลพนักงานเสร็จสมบูรณ์

---

## 7. 🔒 End of Product Sampling

เมื่อผู้ใช้งานตรวจสอบข้อมูลทั้งหมดเรียบร้อยแล้ว และต้องการปิดการบันทึกข้อมูล Sampling ให้กดปุ่ม:

```text
End of Product Sampling
```

เมื่อกดปุ่มดังกล่าว ระบบจะดำเนินการ:

* ล็อกข้อมูล Sampling
* เปลี่ยนสถานะ `Locked_Production` เป็น `1`
* ป้องกันไม่ให้ผู้ใช้งานบันทึกข้อมูลเพิ่มเติมใน Sampling นั้น
* สิ้นสุดกระบวนการบันทึกข้อมูลของ Sampling ดังกล่าว

> ⚠️ หลังจากระบบล็อก Sampling แล้ว จะไม่สามารถเพิ่มหรือบันทึกข้อมูลกล่องนมเพิ่มเติมได้
