# 📄 Document

## 1. รายละเอียดหน้า Document

เมื่อผู้ใช้งานกดเมนู **Document** ระบบจะนำไปยังหน้า:

```text
/Document
```

หน้า Document จะรับค่า `SamplingID` จาก **Update State** ซึ่งใช้สำหรับเก็บและส่งต่อรหัส Sampling ที่ผู้ใช้งานเลือกไว้

ภายในหน้า Document มีเมนูหลักทั้งหมด 3 รายการ ดังนี้:

| ลำดับ | เมนู                          | รายละเอียด                                  |
| ----: | ----------------------------- | ------------------------------------------- |
|     1 | Sampling Status               | หน้าติดตามสถานะของ Sampling                 |
|     2 | Report Production             | หน้ารายงานข้อมูลสำหรับตรวจสอบและพิมพ์เอกสาร |
|     3 | Production Checklist Sampling | กลับไปยังหน้าตาราง `/sampling-tables`       |

---

# 📊 Sampling Status

## 2. รายละเอียดหน้า Sampling Status

เมื่อผู้ใช้งานเลือกเมนู **Sampling Status** ระบบจะตรวจสอบ `SamplingID` ในฐานข้อมูล

หากพบข้อมูล SamplingID ระบบจะแสดงรายละเอียดและสถานะการดำเนินงานของ Sampling รายการนั้น

---

## 3. Sampling Details

แสดงข้อมูลพื้นฐานของ Sampling ดังนี้:

| รายการ       | รายละเอียด                     |
| ------------ | ------------------------------ |
| `SamplingID` | รหัสประจำ Sampling             |
| `Department` | ชื่อแผนกที่สร้าง Sampling      |
| `Machine`    | ชื่อเครื่องจักรที่ใช้ในการผลิต |
| `Create By`  | ชื่อผู้สร้าง Sampling          |
| `Create At`  | วันที่และเวลาที่สร้าง Sampling |

---

## 4. Product Details

แสดงรายละเอียดของผลิตภัณฑ์ ดังนี้:

| รายการ             | รายละเอียด                      |
| ------------------ | ------------------------------- |
| `Product`          | ชื่อผลิตภัณฑ์                   |
| `Flavour`          | รสชาติหรือกลิ่นของผลิตภัณฑ์     |
| `Size`             | ขนาดของผลิตภัณฑ์                |
| `FillingDate`      | วันที่ผลิต                      |
| `ExpiredDate`      | วันหมดอายุ                      |
| `Temperature 30°C` | จำนวนตัวอย่างนมที่อุณหภูมิ 30°C |
| `Temperature 55°C` | จำนวนตัวอย่างนมที่อุณหภูมิ 55°C |

# 🔄 Activity Center

ส่วน **Activity Center** ใช้สำหรับแสดงลำดับขั้นตอนและสถานะการดำเนินงานของ Sampling

จากข้อมูลที่กำหนดไว้ในปัจจุบัน มีทั้งหมด 9 ขั้นตอน ดังนี้

## Step 1 — Create in Process

สถานะการสร้าง Sampling อยู่ระหว่างดำเนินการ

## Step 2 — Work in Process

สถานะ Sampling อยู่ระหว่างการปฏิบัติงานและบันทึกข้อมูล

## Step 3 — Sending Details

แสดงรายละเอียดข้อมูลก่อนส่ง Sampling ประกอบด้วย:

| รายการ            | รายละเอียด                      |
| ----------------- | ------------------------------- |
| `Product`         | ชื่อผลิตภัณฑ์                   |
| `Flavour`         | รสชาติหรือกลิ่นของผลิตภัณฑ์     |
| `Size`            | ขนาดของผลิตภัณฑ์                |
| `FillingDate`     | วันที่ผลิต                      |
| `ExpiredDate`     | วันหมดอายุ                      |
| `Shift 1 Send By` | ชื่อผู้บันทึกข้อมูลนมของกะที่ 1 |
| `Shift 2 Send By` | ชื่อผู้บันทึกข้อมูลนมของกะที่ 2 |
| `Shift 3 Send By` | ชื่อผู้บันทึกข้อมูลนมของกะที่ 3 |
| `Shift 4 Send By` | ชื่อผู้บันทึกข้อมูลนมของกะที่ 4 |

## Step 4 — Waiting for Receive

อยู่ระหว่างรอการรับตัวอย่างนมจากฝ่าย Production

## Step 5 — Receive Details

แสดงรายละเอียดการรับตัวอย่างนม ประกอบด้วย:

| รายการ               | รายละเอียด                                 |
| -------------------- | ------------------------------------------ |
| `Product`            | ชื่อผลิตภัณฑ์                              |
| `Plan Check`         | วันที่วางแผนตรวจสอบตัวอย่างนมอุณหภูมิ 30°C |
| `Plan Check55`       | วันที่วางแผนตรวจสอบตัวอย่างนมอุณหภูมิ 55°C |
| `Example Condition`  | สภาพของตัวอย่าง                            |
| `Indication`         | ลักษณะหรือข้อบ่งชี้ของตัวอย่าง             |
| `Packaging`          | รายละเอียดบรรจุภัณฑ์                       |
| `Amount of Sampling` | จำนวนตัวอย่างนมรวมทั้งหมดของ Sampling      |
| `Send By`            | ผู้ส่งตัวอย่างนมจากฝ่าย Production         |
| `Receive By`         | ผู้รับตัวอย่างนมจากฝ่าย QA                 |

## Step 6 — Waiting for Result

อยู่ระหว่างรอผลการตรวจวิเคราะห์

## Step 7 — Waiting for Physical

อยู่ระหว่างรอการตรวจสอบลักษณะทางกายภาพ

## Step 8 — Supervisor Approve

อยู่ระหว่างรอผู้ควบคุมหรือหัวหน้างานอนุมัติผล

## Step 9 — Finish Sampling

เสร็จสิ้นกระบวนการของ Sampling

> ℹ️ หมายเหตุ: รายการที่ระบุไว้มีทั้งหมด 9 ขั้นตอน หากต้องการให้ Activity Center มี 10 ขั้นตอน จำเป็นต้องเพิ่มรายละเอียดของ Step 10

# 🖨️ Report Production

## 5. รายละเอียดหน้า Report Production

เมื่อผู้ใช้งานเลือกเมนู **Report Production** ระบบจะนำไปยังหน้าเอกสารรายงาน ซึ่งใช้สำหรับตรวจสอบข้อมูลและพิมพ์เอกสารของ Sampling

เอกสารจะแสดงข้อมูลทั้งหมดที่เกี่ยวข้องกับ Sampling ดังนี้:

| ลำดับ | รายการ                   | Field / รายละเอียด               |
| ----: | ------------------------ | -------------------------------- |
|     1 | รหัส Sampling            | `SamplingID`                     |
|     2 | วันที่ผลิต               | `FillingDate`                    |
|     3 | ชื่อผลิตภัณฑ์            | `Product`                        |
|     4 | ชื่อเครื่องจักร          | `Machine`                        |
|     5 | จำนวน Brik อุณหภูมิ 30°C | `Quantity (30°C)`                |
|     6 | จำนวน Brik อุณหภูมิ 55°C | `Quantity (55°C)`                |
|     7 | ลำดับตัวอย่างนม          | ลำดับของแต่ละ Brik               |
|     8 | เวลาเก็บตัวอย่าง         | เวลาที่เก็บตัวอย่างของแต่ละ Brik |
|     9 | สถานะตัวอย่างนม          | `Start`, `Stop`, `Hr.`           |

---

## 6. การจัดแสดงข้อมูลในรายงาน

รายงานจะแบ่งข้อมูลออกเป็น 2 ส่วนหลักตามอุณหภูมิ:

### 🧪 ส่วนที่ 1: อุณหภูมิ 30°C

แสดงข้อมูลตัวอย่างนมที่ตรวจสอบในอุณหภูมิ 30°C ได้แก่:

* จำนวน Brik
* ลำดับ Brik
* เวลาเก็บตัวอย่าง
* สถานะของตัวอย่าง

### 🧪 ส่วนที่ 2: อุณหภูมิ 55°C

แสดงข้อมูลตัวอย่างนมที่ตรวจสอบในอุณหภูมิ 55°C ได้แก่:

* จำนวน Brik
* ลำดับ Brik
* เวลาเก็บตัวอย่าง
* สถานะของตัวอย่าง

การแบ่งข้อมูลตามอุณหภูมิช่วยให้ผู้ใช้งานตรวจสอบข้อมูลของตัวอย่างนมได้อย่างชัดเจน และลดความสับสนระหว่างข้อมูลของอุณหภูมิ 30°C และ 55°C
