# 🖨️ Report Production

## 1. รายละเอียดหน้า Report Production

เมื่อผู้ใช้งานกดปุ่ม **Report Production** ระบบจะนำไปยังหน้าเอกสารรายงาน ซึ่งใช้สำหรับแสดงข้อมูลทั้งหมดของ Sampling เพื่อให้ผู้ใช้งานตรวจสอบและพิมพ์เป็นเอกสารได้

---

## 2. ข้อมูลที่แสดงในรายงาน

| ลำดับ | รายการ                   | Field / รายละเอียด               |
| ----: | ------------------------ | -------------------------------- |
|     1 | รหัส Sampling            | `SamplingID`                     |
|     2 | วันที่ผลิต               | `FillingDate`                    |
|     3 | ชื่อผลิตภัณฑ์            | `Product`                        |
|     4 | ชื่อเครื่องจักร          | `Machine`                        |
|     5 | จำนวน Brik อุณหภูมิ 30°C | `Quantity (30°C)`                |
|     6 | จำนวน Brik อุณหภูมิ 55°C | `Quantity (55°C)`                |
|     7 | ลำดับตัวอย่างนม          | ลำดับของแต่ละ Brik               |
|     8 | เวลาเก็บตัวอย่าง         | เวลาที่เก็บตัวอย่างของแต่ละ Brik |
|     9 | สถานะตัวอย่างนม          | `Start`, `Stop`, `Hr.`           |

---

## 3. รูปแบบการจัดแสดงข้อมูล

ภายในเอกสารรายงาน ระบบจะแบ่งข้อมูลตัวอย่างนมออกเป็น 2 ส่วนตามอุณหภูมิ ดังนี้

### 🧪 ข้อมูลตัวอย่างนมอุณหภูมิ 30°C

แสดงข้อมูล:

* จำนวน Brik ที่บันทึกไว้
* ลำดับของแต่ละ Brik
* เวลาที่เก็บตัวอย่าง
* สถานะของตัวอย่าง ได้แก่ `Start`, `Stop` และ `Hr.`

### 🧪 ข้อมูลตัวอย่างนมอุณหภูมิ 55°C

แสดงข้อมูล:

* จำนวน Brik ที่บันทึกไว้
* ลำดับของแต่ละ Brik
* เวลาที่เก็บตัวอย่าง
* สถานะของตัวอย่าง ได้แก่ `Start`, `Stop` และ `Hr.`

การจัดแสดงข้อมูลแยกตามอุณหภูมิช่วยให้สามารถตรวจสอบจำนวน Brik และรายละเอียดการเก็บตัวอย่างได้อย่างชัดเจน ลดความสับสนระหว่างข้อมูลอุณหภูมิ 30°C และ 55°C
