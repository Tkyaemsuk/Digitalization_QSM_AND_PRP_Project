# PRP2 — Problems and Improvement Ideas

| 2 | ข้อมูล Mixing ควรบันทึกเป็นแถว ไม่ใช่คอลัมน์ | ควรปรับปรุง |

## 1. Export CSV ต้องแปลงคอลัมน์กลับเป็นแถว

**ปัญหา:** PRP2 Export เป็นไฟล์ CSV ได้ แต่ต้องแปลงตารางที่เก็บเป็น **คอลัมน์** (Batch 1…N ในแถวเดียว) กลับเป็น **แถว** (1 Batch = 1 แถว) ก่อน

**ตารางที่เกี่ยวข้อง:** `prp_2_table`, `Mixing_prp2`, `Control_Mixing`, `Recombine_labprp2`

**แนวทาง**
- เก็บเป็นแถวตั้งแต่ต้น เหมือน `Yield_prp2` และ `Finish-good` (ดูข้อ 2)
- หรือทำ Query แปลงคอลัมน์เป็นแถว (UNPIVOT) สำหรับหน้า Export

## 2. ข้อมูล Mixing ควรบันทึกเป็นแถว

**ปัญหา:** ปัจจุบัน Mixing บันทึกเป็นคอลัมน์ (1 แถวเก็บ 5 Batch) ซึ่งทำให้ Export ยาก และตารางกว้าง แก้ไขยาก

**แนวทาง:** ปรับให้ 1 Batch = 1 แถว (ลักษณะเดียวกับ `Yield_prp2`) ซึ่งช่วยทั้งเรื่อง Export (ข้อ 1) และการแก้ไขรายแถว

## 3. ลงข้อมูลแล้วข้อมูลหลุด

**ปัญหา:** แอปมีปัญหาลงข้อมูลแล้วข้อมูลหลุด

**สถานะ:** แก้ไขแล้ว

**หากยังเกิดขึ้นอีก:** ให้ตรวจสอบ **Condition** ของ Component และ Action ที่เกี่ยวข้อง (เงื่อนไขการแสดง / เงื่อนไขการบันทึก)

## 4. สีของตารางตามคอลัมน์

**ปัญหา:** Sup ต้องการให้ตารางใส่สีตามคอลัมน์ เพื่อให้เห็นว่า Batch นี้ลงข้อมูลแล้ว แต่ Budibase ไม่รองรับ

**ทางเลี่ยงที่ใช้อยู่:** ปุ่มเปลี่ยน Batch ที่เปลี่ยนสีตามสถานะ (ดำ = กำลังเลือก, เหลือง = Lab ลงแล้วแต่ยังไม่ผ่าน, เขียว = ผ่าน/ลงครบ, ฟ้า = Sup ตรวจสอบแล้ว)

## 5. ปุ่ม Save ปุ่มเดียว

**ปัญหา:** Operator ต้องการ Save ที่เดียว แต่ข้อมูลมีมาก ถ้า Save รวมกันจะหาตัวที่ผิดได้ยาก

**แนวทาง (ข้อเสนอ)**
- Save แยกตามกลุ่มข้อมูลหรือ Form Step เพื่อให้รู้ว่าผิดที่ส่วนไหน
- ถ้าต้องการปุ่มเดียว ให้ตรวจสอบค่า (Validation) ก่อน Save และแสดงรายการช่องที่ผิดชัดเจน

## 6. ปรับ UX / UI

**ปัญหา:** ต้องการปรับหน้าจอให้ใช้งานสะดวกขึ้น
