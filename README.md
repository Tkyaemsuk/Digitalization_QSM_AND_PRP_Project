| ------------------------- | ----------------------------------- | -----------------------------------

## 2. รายละเอียดหน้า Login

หน้าเข้าสู่ระบบสำหรับยืนยันตัวตนและกำหนดสิทธิ์การใช้งานของผู้ใช้ โดยระบบแบ่งสิทธิ์ตามหน่วยงาน ดังนี้

```text
uht1
uht2
uht3
```

ผู้ใช้งานแต่ละหน่วยงานจะใช้ Username และ Password ตามสิทธิ์ที่ระบบกำหนดไว้

---

## 3. รายละเอียดหน้า Menus

หน้าเมนูหลักของแอปพลิเคชัน ซึ่งผู้ใช้งานจะเข้าสู่หน้านี้หลังจาก Login สำเร็จ โดยระบบแบ่งประเภทการใช้งานออกเป็น 2 ส่วน ได้แก่

1. Low Acid
2. High Acid

การแบ่งเมนูดังกล่าวช่วยให้ผู้ใช้งานสามารถเข้าถึงกระบวนการทำงานที่เกี่ยวข้องกับแต่ละประเภทผลิตภัณฑ์ได้อย่างถูกต้องและเป็นระบบ

---

## 4. รายละเอียดหน้า Create Sampling

หน้า Create Sampling ใช้สำหรับสร้างข้อมูล Sampling และ QR Code เพื่อใช้ในการเก็บตัวอย่างผลิตภัณฑ์นม โดยถือเป็นขั้นตอนแรกของกระบวนการตรวจสอบในส่วน Production

ผู้ใช้งานสามารถบันทึกข้อมูลตามช่วงเวลาการผลิตของแต่ละกะ โดยระบบประกอบด้วยช่องข้อมูลทั้งหมด 9 รายการ ดังนี้

### 4.1 FillingDate

วันที่ผลิตสินค้า

### 4.2 ExpiredDate

วันหมดอายุของสินค้า

### 4.3 Product

ชื่อผลิตภัณฑ์ที่ผลิต โดยเลือกจากรายการที่ระบบกำหนด ได้แก่

```text
D-Malt
D-Whitemalt
UHT-Mik
Other
```

### 4.4 Products

ชื่อผลิตภัณฑ์เพิ่มเติม กรณีเลือก `Other` ในช่อง Product โดยช่องนี้จะแสดงเฉพาะเมื่อผู้ใช้งานเลือกผลิตภัณฑ์เป็น `Other`

### 4.5 Flavour

รายละเอียดรสชาติหรือกลิ่นของผลิตภัณฑ์ที่ผลิต

### 4.6 Department

หน่วยงานหรือแผนกที่ทำการสร้าง Sampling โดยเลือกข้อมูลผ่าน Dropdown

### 4.7 Machine

เครื่องจักรที่ใช้ในการผลิต โดยเลือกข้อมูลผ่าน Dropdown ทั้งนี้ รายการเครื่องจักรจะเชื่อมโยงจาก Data Provider: `Query Get All Machine`

### 4.8 Size

ขนาดของผลิตภัณฑ์ โดยข้อมูลจะเชื่อมโยงกับฐานข้อมูลของ Machine และแสดงผลผ่าน Dropdown

### 4.9 SamplingID

รหัสประจำ Sampling ซึ่งระบบจะสร้างขึ้นโดยอัตโนมัติในรูปแบบ QR Sampling

รูปแบบรหัสมีโครงสร้างดังนี้

```text
ชื่อระบบ-วันที่ผลิต-รหัสหน่วยงานและเครื่องจักร-ลำดับการสร้างประจำวัน
```

ตัวอย่าง:

```text
QSM-07012026-06014-01
```

หลักการกำหนดลำดับ Sampling:

* การสร้าง Sampling ครั้งแรกของวัน ระบบจะเริ่มต้นลำดับที่ `01`
* หากมีการสร้าง Sampling เพิ่มในวันเดียวกัน ระบบจะเพิ่มลำดับต่อเนื่องเป็น `02`, `03`, `04` ตามลำดับ
* เมื่อเปลี่ยนเป็นวันใหม่ ระบบจะรีเซ็ตลำดับกลับมาเริ่มต้นที่ `01`

## 5. โครงสร้างหน้าเมนูหลัก

### Logo

แสดงตราสัญลักษณ์ของระบบ QSM Microbiological Analysis System

### Production Menu

เมนูสำหรับการดำเนินงานในส่วน Production ประกอบด้วย

* Create Sampling — Low Acid
* Production Checklist Sampling — Low Acid
* Create Sampling — High Acid
* Production Checklist Sampling — High Acid

โครงสร้างเมนูดังกล่าวช่วยจัดหมวดหมู่กระบวนการทำงานให้ชัดเจน และช่วยให้ผู้ใช้งานสามารถเลือกใช้งานระบบได้ตรงตามประเภทผลิตภัณฑ์และขั้นตอนการปฏิบัติงาน
